# Week 2 demo capture checklist

**Important:** A repository upload is not a verified working demo. Record a real run with the local open-weight Gemma model.

1. Install Node.js 22+ and Ollama from https://ollama.com/download
2. Run `npm install` and `ollama pull gemma3:4b`.
3. Start Ollama (`ollama serve` if not already running), then `npm run dev`.
4. Open http://localhost:3000, enter **a public HTTPS site that you own or have permission to audit**.
5. Wait until Lighthouse metrics and **nonempty local Gemma recommendations** appear. If an AI unavailable message appears, fix the model connection before claiming the AI feature works.
6. Record 60–90 seconds showing: entering the URL, actual scores, real AI text, downloaded report and the open GitHub source.
7. Upload video to your preferred publicly viewable video platform, then add its link and one real screenshot to DEV_SUBMISSION_DRAFT.md.
8. Complete the DEV Week 2 template and publish before Oct 18 11:59 PM PDT.

No fabricated scores, users, model results, or demo video. Do not expose API keys or private URLs.
